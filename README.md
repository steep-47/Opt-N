# Opt-N

SillyTavern 的动态行动选项点击扩展。

- 自动识别最新 AI 回复中连续编号的行动选项，支持 2 项及以上。
- 支持 `1.`、`1、`、`1）`、`1:`、`①` 等常见编号格式。
- 单击选中，再次点击取消，支持多选。
- 多选执行顺序按照点击顺序。
- 可直接执行，也可先填入输入框继续补充。
- 输入框已有内容时，会作为补充与所选行动一起发送。
- Swipe、消息编辑和聊天切换后重新识别当前最新回复。
- 右滑切换或重新生成时立即卸下旧按钮，并以当前 `swipe_id` 对应正文刷新选项。
- 与 Memo-N 同时启用时，会立即识别行动选项，并在记录块清理完成后再次校验。

## 安装

在 SillyTavern 的扩展管理中选择 **Install Extension / 安装扩展**，输入本仓库地址：

`https://github.com/steep-47/Opt-N`

安装后刷新或重启 SillyTavern。


## 命名

当前扩展名称统一为 **Opt-N**。代码、运行时选择器和界面标识均使用 Opt-N 命名，不再保留旧名称兼容标识。
